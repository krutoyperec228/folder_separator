# Zipper GUI 📦

Утилита для автоматической группировки файлов в ZIP-архивы заданного размера (например, по 15 МБ). 
Отлично подходит для разбивки больших папок с фото, видео или документами на части для отправки по почте или загрузки в облачные сервисы с ограничениями на размер файла.

Программа имеет удобный графический интерфейс (GUI) и поддерживает консольный режим (CLI).

## ✨ Возможности

- **Гибкая настройка размера:** задайте целевой размер архива в мегабайтах (поддерживаются дробные значения, например, `14.5`).
- **Фильтрация по расширениям:** упаковывайте только нужные типы файлов (например, только `.jpg` и `.png`), игнорируя мусор и системные файлы.
- **Умная группировка:** алгоритм сортирует файлы по размеру, чтобы максимально плотно заполнить каждый архив, не превышая заданный лимит.
- **Управление сжатием:** выбор между `deflate` (сжатие) и `store` (без сжатия, быстрее для уже сжатых файлов).
- **Рекурсивный обход:** возможность включать или исключать подпапки.
- **Сохранение настроек:** программа запоминает последние выбранные пути и параметры.
- **Безопасная работа:** защита от перезаписи существующих архивов (создаются копии с суффиксами `_1`, `_2`).
- **Только стандартная библиотека:** для работы не требуются сторонние зависимости (кроме PyInstaller для сборки).
